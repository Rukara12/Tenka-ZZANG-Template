# 텐카 템플릿 에디터

게임 추천 짤방 생성기. 템플릿의 빈 칸에 사진이나 움짤을 얹고 문구를 고쳐
GIF · PNG · 영상으로 저장합니다.

**→ https://rukara12.github.io/Tenka-ZZANG-Template/**

설치할 것도, 로그인할 것도 없습니다. 올린 사진은 서버로 가지 않고 브라우저 안에서만
처리됩니다.

---

## 1. 사진 넣기

칸은 셋입니다. **말풍선**, **핸드폰**, **로고**. 로고만 템플릿 그림 위에 얹히고
나머지 둘은 아래로 깔립니다.

넣는 방법은 네 가지이고 아무거나 쓰면 됩니다.

- 캔버스의 점선 칸을 **클릭**
- 사진 파일을 **끌어다 놓기** — 놓은 자리의 칸으로 들어갑니다
- **`Ctrl+V`** — 스크린샷을 캡처하고 바로 붙여넣을 수 있습니다
- 오른쪽 패널 **구성** 목록에서 칸 이름을 클릭

움짤(GIF)도 사진과 똑같이 넣으면 됩니다. 세 칸에 서로 다른 움짤을 넣어도 각자의
원래 속도로 돕니다.

## 2. 위치와 크기 맞추기

사진을 클릭해 고르면 청록색 테두리와 손잡이가 붙습니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 옮기기 | 드래그 · 방향키(`Shift`+방향키는 10px씩) |
| 크기 | 모서리 손잡이 드래그 (반대쪽 모서리가 고정, `Ctrl`을 누르면 가운데 기준) · 마우스 휠 · 두 손가락 핀치 |
| 화면을 크게 보기 | 상단바의 배율(**맞춤 / − / +**), 또는 `Ctrl`+휠 |
| 회전 | 위로 뻗은 손잡이 드래그 (`Shift`를 누르면 15° 단위) |
| 정확한 값 | 오른쪽 패널의 크기·회전 슬라이더 |
| 90° 돌리기 · 좌우 뒤집기 | 패널의 해당 버튼 |
| 칸을 꽉 채우기 | 패널의 **칸 채우기** (자리만 잡으려면 **가운데로**) — 말풍선·핸드폰 전용 |
| 사진 바꾸기 | 사진을 두 번 클릭 |
| 빼기 | `Delete`, 또는 패널의 **비우기** |

사진을 고르고 있는 동안에는 **보이지 않게 되는 부분이 옅게 비칩니다.** 칸 밖으로
잘려나가는 부분뿐 아니라, 칸 안이지만 그림에 가려지는 부분까지 포함합니다. 말풍선은
칸 넓이의 60% 가량이 그림에 덮이므로, 짙게 보이는 곳만 실제로 나온다고 보면 됩니다.
감으로 밀어 넣지 말고 이걸 보고 잡으세요.

### 로고 효과

로고 칸을 고르면 패널 아래에 **로고 효과**가 열립니다. 밝은 배경에 묻히는 로고는
테두리를, 납작해 보이는 로고는 그림자를 켜면 살아납니다. 둘 다 두께·번짐·색을
조절할 수 있고, 다른 두 칸에는 적용되지 않습니다.

## 3. 문구 고치기

문구는 **좌상단**, **좌하단**, **우상단** 셋입니다.

문구를 **두 번 클릭**하거나, 고른 뒤 **`Enter`**를 누르면 그 자리에서 바로 고칠 수
있습니다. 한글 조합이 깨지지 않으니 평소 타자 치듯 쓰면 됩니다. 다 됐으면 `Esc`나
바깥을 클릭.

- **글자 크기 · 칸 너비 · 칸 높이 · 글자 색** — 패널 슬라이더
- **칸에 맞춰 크기 자동 조절** — 켜두면 칸 안에 들어가도록 크기가 알아서 줄고 늡니다.
  문구를 아직 정하지 못했을 때 편합니다
- **옮기기** — 문구를 드래그
- **칸 모양** — 좌우 손잡이는 너비, 위아래 손잡이는 높이, 모서리 손잡이는 칸과
  글자를 함께 키웁니다. 어느 쪽이든 잡은 반대편은 제자리에 남습니다
- **위치·크기 되돌리기** — 기본값으로 복귀

글자가 **말풍선 밖으로 나가면** 캔버스에 주황색 점선이 뜹니다. 그대로 저장하면
글자가 말풍선을 벗어나 그림 위에 얹힌 채로 나가니, 패널에 같이 뜨는
**말풍선에 맞추기**를 누르면 한 번에 정리됩니다. 입력 상자를 넘겼는지가 아니라
실제 말풍선 모양을 기준으로 판단합니다.

## 4. 도구

**게임 이름으로 로고 찾기** — 게임 이름을 넣고 검색하면 SteamGridDB의 검색 결과가
새 탭에서 열립니다. 마음에 드는 로고를 받아서 로고 칸에 넣으면 됩니다.

**글꼴 바꾸기** — 갖고 있는 글꼴 파일(`.ttf` `.otf` `.woff` `.woff2`)을 직접 올려
쓸 수 있습니다. 단, 올린 글꼴은 브라우저를 닫으면 사라지므로 다음에 이어서 작업할
때 다시 넣어야 합니다.

## 5. 저장하기

오른쪽 위 **내보내기**를 누릅니다.

| 형식 | 쓸 때 |
|---|---|
| **GIF** | 움짤. 커뮤니티에 올리기 가장 무난합니다 |
| **PNG** | 정지 이미지. 움직이는 사진이 없으면 이것만 켜집니다 |
| **영상** | 움짤이 길거나 색이 많아 GIF가 너무 커질 때 (WebM 또는 MP4) |

**크기**는 0.5배(512×383)부터 2배(2048×1530)까지. 대부분 1배로 충분하고, 트위터나
디스코드에 올릴 거면 0.75배로 줄여도 티가 잘 안 납니다.

GIF를 고르면 아래 항목이 더 나옵니다.

- **초당 프레임** — 기본값 *원본 속도*를 그대로 두는 게 가장 자연스럽습니다.
  용량을 줄여야 하면 15 정도로 낮추세요
- **재생 속도** — 0.5배(느리게)부터 2배(빠르게)까지
- **색 수** — 255색이 가장 선명하고, 64색이 가장 가볍습니다

### 저장 전에 용량 확인하기

**용량 측정**을 누르면 64 / 128 / 255색으로 각각 얼마나 나오는지 실제로
몇 프레임 시험 인코딩해서 알려줍니다. 어림수가 아니라 실측 기반이라 대체로 오차가
몇 % 안쪽입니다. 표에서 색 수를 바로 골라 저장할 수도 있습니다.

용량이 예상보다 크다면 **크기 → 초당 프레임 → 색 수** 순으로 낮추는 게 화질 손해가
가장 적습니다.

> 프레임이 아주 많은 움짤은 300장까지만 내보냅니다. 넘으면 초당 프레임을 자동으로
> 낮춰서 **재생 길이는 그대로 유지**합니다. 영상 저장은 실시간 녹화 방식이라
> 재생 길이만큼 시간이 걸립니다.

## 6. 알아두면 좋은 것

**작업은 자동 저장됩니다.** 새로고침하거나 브라우저를 닫아도 다시 열면 사진까지
그대로 이어집니다. 처음부터 다시 하려면 위쪽 **처음부터** 버튼을 누르세요.

**되돌리기가 깊습니다.** `Ctrl+Z` / `Ctrl+Shift+Z`로 200단계까지 오갈 수 있으니
과감하게 이것저것 해보세요.

### 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+V` | 스크린샷 붙여넣기 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 되돌리기 / 다시하기 |
| 방향키 | 1px 이동 (`Shift`와 함께 10px) |
| `Enter` | 고른 문구 편집 시작 |
| `Delete` | 고른 사진 빼기 |
| `Esc` | 선택 해제 · 문구 편집 끝내기 |
| `Ctrl`+휠 | 보기 배율 (사진 크기가 아니라 화면 확대) |

### 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 배경 그림이 안 보인다 | `tenka.png`가 `index.html` 옆에 있어야 합니다 |
| GIF · 영상 버튼이 회색이다 | 움짤을 한 칸이라도 넣어야 켜집니다 |
| 영상 버튼만 회색이다 | 브라우저가 녹화 기능을 지원하지 않습니다 |
| 문구가 안 골라진다 | 글자가 그려진 자리를 눌러야 합니다. 빈 문구는 오른쪽 패널의 **문구** 목록에서 고르세요 |

크롬 · 엣지 · 사파리 · 파이어폭스 최신 버전에서 동작합니다.
