# 텐카 템플릿 에디터

정해진 만화 템플릿의 빈 칸에 사진이나 움짤을 넣고 대사를 고쳐 GIF · PNG · 영상으로
저장하는 웹 편집기입니다.

주소: https://rukara12.github.io/Tenka-ZZANG-Template/

설치나 로그인은 필요하지 않습니다. 불러온 사진은 서버로 전송되지 않으며 브라우저
안에서만 처리됩니다.

---

## 화면 구성

| 영역 | 내용 |
|---|---|
| 캔버스 | 가운데. 편집 중인 짤방이 표시됩니다 |
| 패널 | 오른쪽. 선택한 대상의 설정이 표시됩니다 |
| 상단바 | 배율, 되돌리기, 보관함, 조작법, 처음부터, 내보내기 |

사진이 들어가는 칸은 **말풍선**, **핸드폰**, **로고** 세 곳이며, 대사 칸은
**좌상단**, **좌하단**, **우상단** 세 곳입니다.

## 기본 사용 순서

1. 말풍선 칸을 클릭해 사진을 지정합니다.
2. 대사를 두 번 클릭해 내용을 수정합니다.
3. 상단바의 **내보내기**에서 형식을 고르고 **저장**을 누릅니다.

---

## 사진 넣기

다음 네 가지 방법 중 하나를 사용합니다.

- 캔버스의 점선 칸을 클릭합니다.
- 사진 파일을 캔버스로 끌어다 놓습니다. 놓은 위치의 칸에 들어갑니다.
- `Ctrl+V`를 눌러 복사해 둔 스크린샷을 붙여넣습니다. 커서를 올려둔 칸에 들어갑니다.
- 패널의 **구성** 목록에서 칸 이름을 클릭합니다.

움짤(GIF)도 같은 방법으로 넣습니다. 세 칸에 서로 다른 움짤을 넣으면 각각 원래
속도로 재생됩니다.

패널 아래쪽 검색창에 게임 이름을 입력하면 SteamGridDB의 로고 검색 결과가 새 탭에서
열립니다.

## 사진 조정

사진을 클릭하면 테두리와 손잡이가 표시됩니다.

| 동작 | 조작 |
|---|---|
| 이동 | 드래그 또는 방향키 (`Shift`와 함께 누르면 10px 단위) |
| 크기 | 모서리 손잡이 드래그, 마우스 휠, 두 손가락 |
| 회전 | 위쪽 손잡이 드래그 (`Shift`와 함께 누르면 15° 단위) |
| 칸 채우기 | 패널의 **칸 채우기** |
| 위치 초기화 | 패널의 **가운데로** |
| 90° 회전, 좌우 반전 | 패널의 해당 버튼 |
| 사진 교체 | 사진을 두 번 클릭 |
| 삭제 | `Delete` 또는 패널의 **비우기** |

모서리 손잡이를 끌면 반대쪽 모서리가 고정된 상태로 크기가 바뀝니다. `Ctrl`을 누른
채 끌면 가운데를 기준으로 바뀝니다.

사진을 선택한 동안에는 결과물에 나오지 않는 부분이 옅게 표시됩니다. 진하게 보이는
부분만 저장됩니다.

화면이 작을 경우 상단바의 배율(**맞춤 / − / +**) 또는 `Ctrl`+휠로 확대할 수
있습니다. 사진 크기가 아니라 화면 배율만 바뀝니다.

글씨와 버튼이 작게 보이는 경우 패널의 **화면 크기**에서 100%부터 200%까지 조절할 수
있습니다. 처음 값은 모니터 해상도에 맞춰 정해지며, 한 번 지정하면 유지됩니다.

### 로고 효과

로고 칸을 선택하면 패널에 **로고 효과** 항목이 표시됩니다. 테두리를 켜면 밝은
배경에서 로고가 구분되고, 그림자를 켜면 입체감이 생깁니다. 두께와 색을 조절할 수
있습니다. 이 효과는 로고 칸에만 적용됩니다.

## 대사 입력

대사를 두 번 클릭하면 해당 위치에서 바로 수정할 수 있습니다. 한글 입력이 지원되며,
`Esc`를 누르거나 바깥을 클릭하면 입력이 끝납니다.

패널에서 다음 항목을 조절할 수 있습니다.

| 항목 | 설명 |
|---|---|
| 글자 크기 | 직접 지정 |
| 칸에 맞춰 크기 자동 조절 | 글자 수에 따라 크기가 자동으로 결정됩니다 |
| 칸 너비 · 칸 높이 | 대사가 들어가는 영역의 크기 |
| 글자 색 | 색상 선택 |
| 위치·크기 되돌리기 | 기본값으로 복원 |

글자가 말풍선 밖으로 나가면 주황색 점선이 표시됩니다. 이때 패널에 나타나는
**말풍선에 맞추기**를 누르면 크기와 위치가 자동으로 조정됩니다.

### AI가 만든 대사 불러오기

정해진 형식으로 된 대사 파일을 읽어 세 칸에 한 번에 넣을 수 있습니다. 넣은 뒤에는
각 칸의 말풍선에 맞춰 크기와 위치가 자동으로 조정됩니다.

파일은 다음 형식입니다.

```json
{
  "게임": "게임 이름",
  "우상단": "텐카쨩이 담담하게 권하는 말",
  "좌상단": "나쨩의 반박",
  "좌하단": "텐카쨩이 못 들은 척하며 늘어놓는 옹호"
}
```

세 칸은 이야기 순서대로 이어집니다. 텐카쨩이 담담한 얼굴로 게임을 권하고(우상단),
나쨩이 정색하고 지적하면(좌상단), 텐카쨩이 못 들은 척하며 장황하게 옹호합니다(좌하단).

기본 글자 크기를 유지하면서 들어가는 분량은 우상단 36자, 좌상단 24자, 좌하단 77자
정도입니다. 넘으면 자동으로 글자를 줄여 맞춥니다.

불러오는 방법은 세 가지입니다.

- 패널의 **대사 불러오기**로 파일을 지정합니다.
- 파일을 캔버스로 끌어다 놓습니다.
- 내용을 복사해 `Ctrl+V`로 붙여넣습니다.

`"게임"` 값이 있으면 로고 검색창에 자동으로 채워집니다. JSON이 아니라
`우상단: …` 처럼 이름을 붙인 세 줄이나 번호를 매긴 세 줄도 읽습니다.

패널의 **글꼴 바꾸기**로 글꼴 파일(`.ttf`, `.otf`, `.woff`, `.woff2`)을 지정할 수
있습니다. 지정한 글꼴은 저장되어 다음에 열 때도 유지되며, 기본 글꼴과는 바로 아래
버튼으로 전환합니다.

## 저장

상단바의 **내보내기**를 누르면 형식과 옵션을 지정하는 창이 열립니다.

| 형식 | 용도 |
|---|---|
| GIF | 움짤. 대부분의 커뮤니티에서 사용 가능합니다 |
| PNG | 정지 이미지. 움직이는 사진이 없으면 이 형식만 선택됩니다 |
| 영상 | 움짤 길이가 길어 GIF 용량이 과도할 때 사용합니다 |

크기는 0.5배(512×383)부터 2배(2048×1530)까지 지정할 수 있습니다. 일반적인 용도에는
1배로 충분하며, 0.75배로 줄여도 화면상 차이는 크지 않습니다.

PNG는 **복사** 버튼으로 클립보드에 넣을 수 있습니다. 파일을 저장하지 않고 다른
프로그램에 `Ctrl+V`로 붙여넣을 때 사용합니다. GIF와 영상은 클립보드 복사를 지원하지
않으므로 파일로 저장해야 합니다.

### 용량 조절

**용량 측정**을 누르면 색 수별 예상 용량이 표로 표시되며, 표에서 색 수를 선택한 뒤
바로 저장할 수 있습니다.

용량을 줄여야 할 경우 **크기 → 초당 프레임 → 색 수** 순으로 낮추는 것이 화질
손실이 가장 적습니다. 초당 프레임은 15 정도까지 낮춰도 움직임이 부자연스럽지
않습니다.

영상 저장은 실제 재생 시간만큼 소요됩니다.

## 작업물 관리

작업 내용은 자동으로 저장되며, 새로고침하거나 브라우저를 닫아도 유지됩니다. 저장
상태는 상단바에 표시됩니다.

상단바의 폴더 아이콘을 누르면 **보관함**이 열립니다. 현재 작업을 이름을 붙여
저장하고, 목록에서 선택해 불러올 수 있습니다. 사진도 함께 보관됩니다. 같은 배치로
내용만 바꿔 여러 장을 만들 때 사용합니다.

**처음부터**를 누르면 현재 작업이 초기화됩니다. 보관함의 내용은 삭제되지 않습니다.

되돌리기는 `Ctrl+Z`, 다시하기는 `Ctrl+Shift+Z`입니다.

## 단축키

상단바의 `?` 버튼에서도 확인할 수 있습니다.

| 키 | 동작 |
|---|---|
| `Ctrl+V` | 스크린샷 붙여넣기 (커서를 올려둔 칸) |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 되돌리기 / 다시하기 |
| 방향키 | 1px 이동 (`Shift`와 함께 누르면 10px) |
| `Enter` | 선택한 대사 편집 시작 |
| `Delete` | 선택한 사진 삭제 |
| `Esc` | 선택 해제, 편집 종료 |
| `Ctrl`+휠 | 화면 배율 조절 |

## 문제 해결

| 증상 | 원인 |
|---|---|
| GIF·영상 버튼이 선택되지 않음 | 움짤이 한 칸도 들어 있지 않은 경우입니다 |
| 영상 버튼만 선택되지 않음 | 사용 중인 브라우저가 녹화 기능을 지원하지 않습니다 |
| 대사가 선택되지 않음 | 글자가 표시된 위치를 클릭해야 합니다. 내용이 비어 있는 대사는 패널의 **문구** 목록에서 선택합니다 |
| 복사 버튼이 선택되지 않음 | PNG 형식에서만 사용할 수 있습니다 |
| 수정한 내용이 반영되지 않음 | 잠시 후 새로고침합니다 |

크롬, 엣지, 사파리, 파이어폭스 최신 버전에서 동작합니다.
